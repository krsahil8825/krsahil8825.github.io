# Portfolio Website

Personal portfolio website built with Astro to present projects, technical blogs, and professional background.

Live site: [krsahil.co.in](https://krsahil.co.in)

## Overview

This website is designed to be fast, accessible, and easy to navigate. It reflects my focus on clean engineering practices and practical software development.

## Tech Stack

- Astro
- Tailwind CSS
- TypeScript
- GitHub Pages (deployment)

## Features

- Responsive and lightweight design
- Project showcase with detailed write-ups
- Blog section for technical content
- SEO-focused static site generation

## Getting Started

### Prerequisites

- Node.js 20+
- npm

### Run Locally

```bash
git clone https://github.com/krsahil8825/krsahil8825.github.io.git
cd krsahil8825.github.io
npm install
npm run dev
```

Open [http://localhost:4321](http://localhost:4321).

## Scripts

- `npm run dev` - Start local development server
- `npm run build` - Build production output
- `npm run preview` - Preview production build locally

## Deployment

Deployment is handled through GitHub Actions and published to GitHub Pages.
